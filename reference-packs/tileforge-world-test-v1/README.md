# TileForge World Test Reference Pack v1

This is a copied, pinned subset of TileForge's sprite-reference pack for
TileForge Actor Studio M05. It contains four ground-truth 1x scenes in all four
themes:

- scale lineup
- forest clearing
- Crownhold
- Tidewater

`manifest.json` is the machine-readable authority for source identities,
viewports, actor placements, and ground samples. Every copied PNG is bound to
its upstream SHA-256 identity. Actor Studio reads this pack and never writes
back to TileForge.
