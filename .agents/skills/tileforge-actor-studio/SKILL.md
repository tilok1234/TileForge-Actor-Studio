# TileForge Actor Studio

1. Read `AGENTS.md`, `docs/AGENT_WORKFLOW.md`, and
   `contracts/tileforge-actor-32-v1.json`.
2. Use the Actor Studio MCP tools when connected.
3. Read or create the newest Concept generation request before image work.
   Use its exact prompt with a native image tool included in the connected
   client's subscription, then import each output as a separate immutable
   candidate. Never connect a paid API or request credentials.
4. Preserve every generated candidate as an immutable revision.
5. Report validation evidence separately from visual judgment.
6. Stop for the user's explicit approval before promoting final art.

Do not modify external TileForge or animation-editor repositories. Do not
expand the workflow beyond 32 px mobs and NPCs without an explicit scope change.
